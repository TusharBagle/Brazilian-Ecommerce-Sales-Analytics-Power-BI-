# Brazilian Ecommerce Sales Analytics (Power BI)

# 📊 PowerBI Olist Ecommerce Analytics

A professional **Power BI Business Intelligence Dashboard** built using the **Olist Brazilian E-commerce Dataset**. This project transforms raw e-commerce data into interactive dashboards that provide insights into sales performance, payment trends, customer behavior, and geographic distribution.

---

## 🚀 Project Overview

This Power BI project focuses on analyzing e-commerce operations through three interactive dashboards:

- 📈 Sales Overview
- 💳 Payments & Reviews
- 🌍 Geographic Analysis

The dashboards help stakeholders monitor KPIs, identify business trends, and make data-driven decisions.

---

## 📌 Key Features

- 📦 Total Orders KPI
- 💰 Total Revenue Analysis
- 🛒 Average Order Value (AOV)
- ⭐ Average Customer Review Score
- 📊 Top Product Categories by Revenue
- 💳 Payment Method Distribution
- 📅 Monthly Order Trends
- 🗺️ Customer Order Distribution by State
- 🏙️ Top Seller Cities by Revenue
- 📍 Revenue Distribution by Seller State
- 🎯 Interactive Filters (Year, Order Status, Product Category)

## 🎯 Business Insights

- Credit Card is the most preferred payment method.
- São Paulo generates the highest seller revenue.
- Revenue is concentrated in a few major Brazilian states.
- Customer review scores remain consistently high across most product categories.
- Monthly order volume highlights seasonal purchasing patterns.
